# Semana 03 – Introdução ao JavaScript

Desafios práticos de variáveis, funções e controle de fluxo, todos em `app.js`.

## Como executar

- **Node.js:** `node app.js`
- **Navegador:** cole o conteúdo do `app.js` no Console (F12).

## Conteúdo

1. **Variáveis e tipos:** `let` e `const` (o `TypeError` ao reatribuir uma constante é capturado e explicado), `typeof` em cada primitivo (`typeof null` retorna `"object"`, um bug histórico) e template literals comparados com concatenação.
2. **Funções:** função declarada (sofre hoisting), função de expressão (gera `ReferenceError` se chamada antes), `dobro` nas três formas e parâmetro com valor padrão.
3. **Controle de fluxo:** `if/else`, `switch`, laços `for` e `while` (tabuada, contagem regressiva, par/ímpar) e `diaDaSemana` com `default`.
